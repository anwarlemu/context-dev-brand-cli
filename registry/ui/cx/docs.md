---
name: cx
type: ui
version: 1.1.0
use_for: Join and merge class names. A class passed in replaces the default it conflicts with. Every registry component uses it.
never:
  - Building class strings with raw values; cx only joins token classes
npm: [tailwind-merge@^3]
example: cx.example.tsx
---

Joins class names, drops falsy values, and merges conflicts with tailwind-merge configured for the
brand tokens (generated by `npm run tokens`), so `cx('text-white', 'text-brand')` gives `text-brand`.
